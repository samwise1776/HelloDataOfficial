HELLODATA SYNTAX

Code that reads almost like English.

HelloData focuses on simple commands instead of long database statements.

01

Create a table.

02

Add structured data.

03

Search using conditions.

students.hdata 
# Create our students table

make students {

    name: text

    grade: number

    language: text
}


# Add a student

add students {

    name: "Sam"

    grade: 9

    language: "Java"
}


# Find students

get students
where grade == 9
