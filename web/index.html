ABOUT

What is HelloData?

HelloData is a beginner-friendly database language made to simplify the way you create, store, find, update, and delete data.

HELLODATA CODE

Database code that actually looks simple.

Instead of starting with complicated database syntax, HelloData uses commands that are easier to understand.

example.hdata 

make users {
    name: text
    score: number
}

add users {
    name: "Alex"
    score: 100
}
